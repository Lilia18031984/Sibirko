# Movie Library - Личная кинотека

**Автор:** Сибирко Павел

## 📝 Описание

**Movie Library** - это удобное графическое приложение для ведения личной коллекции фильмов. Программа позволяет добавлять информацию о просмотренных фильмах, отслеживать рейтинги, фильтровать коллекцию по жанрам и годам выпуска, а также экспортировать данные для резервного копирования.

## ✨ Основные возможности

- ➕ **Добавление фильмов** - внесение информации о фильме (название, жанр, год, рейтинг)
- 📋 **Просмотр коллекции** - все фильмы отображаются в удобной таблице
- 🔍 **Фильтрация по жанру** - быстрый поиск фильмов по выбранному жанру
- 📅 **Фильтрация по году** - поиск фильмов за определённый период
- ⚡ **Быстрые фильтры** - однокликовая фильтрация по популярным жанрам
- ✏️ **Редактирование** - возможность изменять информацию о фильме
- 🗑️ **Удаление** - удаление фильмов из коллекции
- 📊 **Статистика** - отображение количества фильмов, среднего, лучшего и худшего рейтинга
- 💾 **Автосохранение** - все данные автоматически сохраняются в JSON-файл
- 💿 **Экспорт данных** - возможность сохранить коллекцию в отдельный JSON-файл
